Referee manual

How to set up and run a multiplayer (play by email) game with the page. Read the player manual first: the players' part of each step is described there.

Setting up the game

  1. Game › Scenarios: start the scenario (click Start scenario twice), or set up the aircraft in the Aircraft tab: data card, counter, pilot quality, ace, hero, crack shot, formation leader and, on each leader, the formation type (fixed or flexible) and « no radio »; then the position line of each aircraft (for example D3A2 #1 (Tapper), 2735, SE, 14.0, 5.0+, LV, 0.0, LVL, [loaded]), or Paste position lines.
  2. Scenario tab: name, game length, special rules, map and its base altitude.
  3. Game › Multiplayer (PBEM): tick Multiplayer game; write the Players (your name included), choose the Referee (you), set This copy is played by to your name, and choose who flies each aircraft (Flown by).
  4. Send the game folder (the page with its maps, counters and boxes folders) to the players, then the first game file: Send game file to players in the bar.

1. Declarations and initiative

The bar shows Initiative declarations — players and the players whose orders have not arrived yet.

  1. When the players' declarations files arrive, click Import orders… and choose them (several at once if you like). The page checks that each file belongs to this game, this turn and this step, and takes only the orders of each player's own aircraft.
  2. Check the Initiative tab: tailing (✓ = allowed now, else the missing condition is written in red), formations in their parameters, out-of-control and unsighted aircraft.
  3. Click Roll initiative and start the moves. The page rolls each aircraft's D10 with its modifiers, breaks the ties, rolls the side rolls (fixed formations, H, M, out-of-control aircraft) and makes the order of movement (8.1). The state at the roll (out of control, unsighted, fixed formation) is kept for the whole turn. It then saves the game file for the player of the first aircraft.

2. Movement Phase

The game file goes from player to player in the order of movement; when two aircraft in a row are flown by the same player, there is no new file. You may move an aircraft yourself (a player who cannot answer, an aircraft flown by the referee): select it when it is its turn, plot and apply its move, then Done: pass to next aircraft. When the last aircraft has moved, the file comes back to you and the bar shows Combat Phase — referee.

3. Combat Phase and end of turn

  1. If a player should be able to change his attacks after seeing the final positions, click Request combat orders: the page saves a game file for the players; import their combat orders with Import orders….
  2. Click Resolve declared attacks. In the order of the Combat Phase (8.3): declared defensive fire, then the fixed gun attacks in the order of movement (an aircraft shot down in this phase still fires), then the jettisons. An attack that is no longer possible is cancelled and said so. Each shot is written in the PBEM format in the shooter's Log and in Combat › Shots this turn: range, deflection, odds, LH modifiers, roll, hits, critical hits and their effects, ammunition.
  3. You can also fire an attack yourself in the Combat tab: Fire (%), Defensive fire (%), Jettison stores. A head-on attack inside the collision risk range asks the pilot's determination roll; the danger zone after it is to be watched on the map.
  4. End of turn checks (Combat tab): fire progress, oil or coolant leaks, recharge of jammed defensive guns, collisions (unsafe stacks, range 0 attacks without tailing; % ≥ 85). Click Roll for each one.
  5. Click Next game turn: the page saves the game file for the players, and the new turn starts with the declarations.

Damage, severe damage, critical hits (engine, fuel, cockpit and crew, wings, equipment, flight controls), lost guns, wounded crew, reloading guns and the +2 initiative after a kill are kept by the page and applied in the next turns (flight limits, shot modifiers, initiative).

Victory points

Game › Victory points adds up the points so far. The scenario booklet is not in the game folder: the page assumes that an aircraft shot down gives the second « Victory Points » number of its data card, a severely damaged one the first, and a pilot killed his crew VP (13.2). The scenario's own bonus is added (Jolly Rogers: +1 to the Japanese for each Val still carrying its bomb). Check against the scenario booklet.

Fixing a mistake

  • A move applied by mistake: select the aircraft, Maneuver › Undo apply.
  • A position to correct: Aircraft tab, edit the position line and press Enter.
  • An aircraft removed from play by mistake: Aircraft tab, Back in play.
  • Going back to an earlier phase: Import game file… with the file saved at the end of that phase.

Good to know

  • Save at the end of each phase and keep every file received and sent.
  • Game › Dice rolls lists every roll of the game (turn, aircraft, what was rolled): the players can check them.
  • The player who receives a file is named in the file name: <scenario> - GT3 - MPH - to Kent.json.
